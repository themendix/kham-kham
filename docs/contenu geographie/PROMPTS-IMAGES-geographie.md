# Prompts d'images — Matière Géographie (54 pays)

Ce document fournit, pour chacun des **54 cours de Géographie** de Sankofa, un **prompt de génération d'image** prêt à copier-coller. Les prompts sont en **anglais** (meilleurs résultats sur DALL·E, Firefly, Nano Banana, Midjourney…) et **autonomes** : chaque prompt contient déjà le bloc de style, tu peux en copier n'importe lequel tel quel.

Objectif : que les cartes de Géographie aient le **même rendu illustré que celles d'Histoire** (voir « Le royaume d'Aksoum »), afin qu'elles utilisent le même en-tête image de 150 px — ce qui aligne aussi la pastille « Terminé » et supprime le « DZ/EG ».

---

## 1. Principe : un style commun + une scène par pays

Chaque prompt combine :

1. **La scène** — spécifique au pays : un **monument ou un paysage emblématique**, un **personnage facultatif**, et **obligatoirement le drapeau du pays**.
2. **Le bloc de style** — identique pour les 54, il garantit l'unité graphique (repris tel quel des prompts d'Histoire).

### Bloc de style commun (référence)

> *flat vector editorial illustration, bold uniform black outlines (neo-brutalist), solid flat color fills with no blur and no photorealism, warm African palette of terracotta/sienna, ochre-gold, savanna green and deep indigo on a single flat background color with cream accents, dark-brown-skinned figures with dignified heroic expressions, clean geometric shapes, subtle flat grain texture, horizontal banner composition (about 3:2) with the main subject centred and clear of the edges, no text, no lettering, no numbers, no watermark.*

---

## 2. Consignes d'utilisation (à lire une fois)

- **Le drapeau est obligatoire** : il apparaît dans chaque image, sur une hampe sur le côté ou flottant, **dans ses vraies couleurs nationales** (c'est la seule exception à la palette « terre/ocre » du bloc de style). Sa description figure dans chaque prompt pour que le générateur le rende correctement (les IA se trompent souvent sur les drapeaux) — vérifie qu'il est fidèle, refais sinon.
- **Personnage facultatif** : une silhouette/scène humaine est proposée quand elle est pertinente ; tu peux la garder ou l'enlever, l'important reste **drapeau + décor emblématique**.
- **Zones de sécurité** : la carte pose une pastille en **haut-gauche** et un cœur en **haut-droite**. Garde ces deux coins **dégagés** (sujet centré ou légèrement bas, pas de visage ni de drapeau dans les coins supérieurs).
- **Format** : bannière paysage **~3:2**, sujet centré.
- **Fond uni** : un seul aplat de couleur en fond, jamais de dégradé flou (`blur`) — c'est la signature du style.
- **Pas de texte** : « no text, no lettering » est déjà dans chaque prompt ; refais l'image si des lettres parasites apparaissent.
- **Cohérence** : garde le **même générateur** (et si possible la même graine / le même style de référence) pour les 54, comme pour l'Histoire.

### Nommage & mise en place (aucune modif de code nécessaire)

- Exporte chaque image en **`.webp`**.
- Nomme le fichier **exactement d'après l'id du cours** : `course-geographie-NN-slug.webp`.
  Ex. `course-geographie-01-algerie.webp`, `course-geographie-20-senegal.webp`, `course-geographie-54-zimbabwe.webp`.
- Dépose les fichiers dans **`src/assets/cours/`** (le même dossier que les images d'Histoire).
- `getCourseImage` (`src/lib/courseImages.ts`) résout automatiquement l'image par le nom = id du cours : dès qu'un fichier est présent, la carte du pays bascule sur l'en-tête image de 150 px. Rien d'autre à câbler.

- **Export en `.webp`**, nom = id du cours (`course-geographie-NN-slug.webp`), dépôt dans `src/assets/cours/`. Le branchement est automatique via `getCourseImage`.
- Vérifie que **le drapeau est fidèle** (couleurs et disposition) — c'est le point que les générateurs ratent le plus souvent.
- Garde **les deux coins supérieurs dégagés** (pastille « Terminé » à gauche, cœur à droite).
- Même générateur / même style de référence pour les 54, pour une collection homogène avec l'Histoire.
